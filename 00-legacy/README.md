# Legacy Bash version (1.x)

Исходная версия HomeLAN была Bash-проектом с несколькими скриптами и конфигурационными файлами. В исходном snapshot dump от 16.11.2026 она представлена в виде последовательной выгрузки файлов с заголовками `========== <path> ==========`.

## Известный состав

- `kid-ctl.sh` — административный Bash-пульт.
- `provision.sh` — первоначальная настройка целевых Linux-машин.
- `kid-session-tick.sh` — локальный тикер учёта активного времени.
- `.bash_aliases` — функции `LOCKNOW`, `SESSION` и сокращения.
- `lib/config.sh`, `lib/args.sh`, `lib/ui.sh`, `lib/transport.sh`, `lib/actions.sh` — библиотечные части.
- `README.md` / `home_lan_README.md`, `AGENTS.md`, `CHANGELOG.md`, `docs/*`.

## Восстановление точного исходника

Оригинальная выгрузка обнаружена в Library как `Вставленный текст.txt` (154457 bytes, 16.11.2026; 2977 строк). Её следует импортировать в Git как исторический исходник после получения байтов файла. Этот архив не содержит реконструированных вместо оригинала скриптов: это намеренно, чтобы не исказить рабочую версию.

См. `../04-source-recovery/`.
