# Legacy behavior inventory

Это краткая карта поведения исходной системы, а не замена исходному коду.

| Механизм | Историческая семантика |
|---|---|
| PASSWORD / `newpass` | Смена пароля через `chpasswd`; сброс файлов окна `.use` и `.expired`; открытие нового окна использования. |
| LOCK (старый) | Создание `/etc/kid-ctl/lock.on`; удаление параметров autologin из LightDM drop-in с сохранением прочих настроек. Это НЕ новая семантика `homelan lock`. |
| AUTOLOGIN | Восстановление autologin и снятие старого lock-флага. В новой архитектуре разблокировка должна быть отдельным явно спроектированным действием. |
| LOCKER | Автоблокировка по idle через `kidctl.timer`, `IDLE_<kid>` в `/etc/kid-ctl/timer.conf`; 0 отключает. |
| LOCKNOW | Немедленная блокировка экрана через `light-locker-command -l`, fallback `loginctl lock-session`; пароль не меняется. |
| TIMER | Отложенные `lock`, `logout`, `poweroff`, отмена. `poweroff` требует переработки: явное подтверждение обязательно. |
| ARM | Учёт активного времени; при истечении сброс пароля и блокировка экрана; компьютер не выключает. |
| PROVISION | Монолитная настройка; в новой версии оставить только HomeLAN-owned механизмы, общую настройку ОС вынести наружу. |

Критическое ограничение: устройства работают по Wi-Fi, Wake-on-LAN не поддерживается.
